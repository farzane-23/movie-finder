Movie Finder

A responsive movie discovery website built with HTML, CSS, and Vanilla JavaScript using the TMDB API.

About the Project

Movie Finder allows users to search for movies, explore movie genres, and view detailed information about their favorite films.

Features

- Search movies by title.
- Display live search suggestions.
- View movie details.
- Browse popular movies.
- Explore movies by genre.
- Pagination for movie results.
- Responsive design for different screen sizes.
- Loading and error handling.

Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- TMDB API
- Git and GitHub

Project Pages

- Home: Browse popular movies and search for movies.
- Movie Details: View detailed information about a selected movie.
- Genre: Explore movies by genre.
- Search Results: View movies matching a search query.

Installation and Usage

1. Clone the repository:
   
   git clone https://github.com/farzane-23/movie-finder.git

2. Open the project folder.

3. Configure your TMDB API credentials.

4. Run the project using a local development server, such as VS Code Live Server.

API

Movie data is provided by "The Movie Database (TMDB)" (https://www.themoviedb.org/).
